# Evidence-Driven Requirements Elicitation for Human-State Monitoring

## Supporting data for anonymous peer review

This repository provides selected research records for a study of evidence-driven requirements elicitation using automotive driver monitoring as a case study.

### Files

| File | Description |
|---|---|
| `search_log.csv` | Recorded literature search runs |
| `search_queries.csv` | Search query records |
| `screening_decisions.csv` | Title/abstract screening decisions for 7,777 records |
| `selected_170_publications.csv` | Bibliographic list of 170 prioritized publications |
| `consolidated_requirements.csv` | Catalogue of 28 consolidated requirements |
| `verification_criteria.csv` | Verification criteria and VC/VD classifications for 28 requirements |
| `conflict_analysis.csv` | Records of 16 potential evidence tensions |

### Scope and limitations

This is a **supporting-data package**, not a complete computational replication package. It does not include the original prioritization script or scoring inputs, second-analyst decision records, or the unreconciled historical evidence-unit/candidate-requirement mapping tables. It therefore does not independently reproduce every step or count in the manuscript.

The screening decisions were initially generated with LLM assistance and only a subset was human-checked; the supplied records should not be interpreted as fully human-verified.

### Data reuse and attribution

Bibliographic metadata identifies third-party publications; the full texts are not redistributed. Please cite the accompanying anonymized manuscript when referencing the study's research outputs. Anonymity and data-sharing permissions should be checked again before posting publicly.
